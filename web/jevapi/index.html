1. The document

Use your own AI key for your own PDFs

Your key goes with each request to the AI company you pick, through JevAPI's free endpoint. JevAPI's code does not save or log it, and this page forgets it when you close the tab. For full control, run the open-source package yourself.

Check every field with Jev (your TypeSafe key)

Jev is TypeSafe's decision model. It reads the document and answers, per field, "does the document really say this?" with a probability. Its answer replaces the extractor's own confidence. Your key goes to this site's API for one request and our code never stores it. Get a key at TypeSafe.
