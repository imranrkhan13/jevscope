How it works

Three steps. One request to Jev per document.

1

Send the text and values

Values from your own extractor or your AI. Or send only the text, and JevAPI finds the fields for resumes and labelled lines.

2

Jev checks each field

For every field Jev answers "does the document really say this?" as a probability, or picks the right option from your list.

3

Fill or review

Fields that clear your bar are filled. The rest go to a person with a plain reason. Calibrate on your own labelled documents when you are ready.

A few lines in your app

Call the free hosted API from any language, or run the open-source package inside your own server.

Quickstart → 
# Check values against the document
curl -X POST https://jevscope.vercel.app/api/v1/verify \
  -H "X-Jev-Key: $TYPESAFE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"text": "...",
       "fields": [{"name": "due_date",
                   "value": "12 Sep 2026"}]}'

# Back comes a decision per field
{"field": "due_date",
 "action": "review",
 "confidence": 0.02,
 "reason": "... Below the 95% bar,
            so a person should check it."}
